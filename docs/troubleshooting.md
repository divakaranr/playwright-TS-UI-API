# Troubleshooting

| Symptom                                                        | Cause                                          | Fix                                                                                                           |
| -------------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `ConfigurationError: Invalid environment variables`            | Invalid/missing variable                       | Read the listed issues; compare with `.env.example`.                                                          |
| `Missing credentials for role "admin"`                         | `APP_ADMIN_USERNAME`/`PASSWORD` unset          | Set them in `.env` (local) or CI secrets.                                                                     |
| Login fails although the password is right                     | Unquoted `#` in `.env` truncates the value     | Quote it: `APP_ADMIN_PASSWORD="Admin#12345"`.                                                                 |
| Logged in as your Windows user name                            | Using `USERNAME`                               | Use `APP_<ROLE>_USERNAME` (framework never reads `USERNAME`).                                                 |
| `No stored session for role "admin"`                           | Ran a browser test without the `setup` project | Run through a browser project (`--project=chromium`) or `npx playwright test --project=setup` first.          |
| `Error: http://localhost:4000/api/health is already used` (CI) | Demo app already running                       | Stop it, or set `PW_REUSE_SERVER=true`.                                                                       |
| `EnvironmentPolicyError: Write blocked`                        | Write against a read-only environment          | Intended. For approved prod writes: `ALLOW_PROD_WRITES=true` + `PROD_WRITE_ALLOWLIST="POST /path"`.           |
| Test skipped with "read-only"                                  | Not tagged `@prod-safe` in prod                | Intended.                                                                                                     |
| `Test data cleanup failed`                                     | Cleanup API call failed (data leaked)          | Check the listed items; leaked users have the `qa-auto.example.com` domain.                                   |
| Allure report command fails                                    | Java missing                                   | Install Java 17+; Allure results are still produced.                                                          |
| MCP host shows no tools / handshake errors                     | Server printed to stdout or failed to start    | Run `npm run build`; check `logs/framework.log`; stdout is reserved – never add `console.log` in server code. |
| MCP `ENVIRONMENT_POLICY_VIOLATION`                             | Environment not in `MCP_ALLOWED_ENVIRONMENTS`  | Add it (never `prod`).                                                                                        |
| MCP `RUN_IN_PROGRESS`                                          | Another run is executing                       | Wait or check `get_framework_status.activeRun`.                                                               |
| `LLM_NOT_CONFIGURED` / `No LLM provider configured`            | AI feature without provider                    | Set `LLM_PROVIDER`, `LLM_MODEL` (+ `LLM_API_KEY`). `npm run ai:check` verifies.                               |
| `[ollama] network error: fetch failed`                         | Ollama not running                             | `ollama serve` and `ollama pull <model>`.                                                                     |
| `LLM_RATE_LIMIT` after retries                                 | Provider quota                                 | Lower concurrency, raise `LLM_MAX_RETRIES`, or switch model.                                                  |
| Trace viewer                                                   | –                                              | `npx playwright show-trace test-results/<test>/trace.zip`                                                     |
| Debug a single test                                            | –                                              | `npm run test:debug -- tests/ui/auth/login.spec.ts` or `npx playwright test --ui`                             |
